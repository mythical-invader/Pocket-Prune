# v0.1.0-M1 — Setup + First Compression

**Date:** 15 Nov 2026 (target was 22 Nov 2026) · **Phase 1 complete: 25 %** of the project
(27 % including WP-09 from Phase 2).

## What this milestone proves

PocketPrune can take a real model from Hugging Face and compress it on our own laptop: the CLI
pipeline downloads SmolLM2-135M at a pinned commit, converts it to an F16 GGUF, quantizes it to
Q5_K_M and Q4_K_M, and every file passes the smoke test — with byte-identical files on a re-run.
The website shows the catalog and device profiles, both laptops share one MongoDB Atlas database,
and the risky part of the project (llama.cpp on Windows) is done.

## Highlights

- **llama.cpp b12376** on native Windows 11, installed by `npm run setup:llamacpp` (all on D:).
- **SmolLM2-135M** by hand: F16 258 MiB → Q4_K_M 101 MiB (−61 %), generation 105 → 199 tok/s,
  perplexity 18.92 → 19.87 (+5 %).
- **CLI pipeline** (`npm run pipeline`) with time limits, log lines and reproducible SHA-256s;
  **fake pipeline** so the website can be built without llama.cpp.
- **Every catalog model tried**: 7 of 8 compress and pass the smoke test (up to Phi-3.5-mini,
  3.8 B); the gated Llama-3.2 needs a Hugging Face token.
- **Website**: theme, reusable components, Catalog, Profiles and Job Setup pages.
- **Shared database**: MongoDB Atlas M0, seeded with the 8 catalog models and the demo user.
- 64 automated tests, CI on every PR.

## Known limits

- Branch protection on `main` is not active (private repo); the PR + review rule is followed by hand.
- On the model machine, Node cannot resolve `mongodb+srv://` addresses, so `.env` uses the standard
  `mongodb://host1,host2,host3/...` form of the Atlas string.
- Preflight, jobs from the website, the worker and live progress come in Phase 2 (M2).
