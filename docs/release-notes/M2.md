# v0.2.0-M2 — Website Job End-to-End

**Date:** 15 Nov 2026 (target was 6 Dec 2026; mid-term on 7 Dec) · **Phase 2 complete: 40 %** of
the project — the mid-term target.

## What this milestone proves

A user can start a **real compression from the website** and watch it happen: pick SmolLM2-135M
on the Catalog → choose levels and a device profile on Job Setup → **Run preflight** (9 server
checks) → tick the licence → **Start compression** → the Job Progress page updates every 2 s while
the worker on the model machine downloads, converts, quantizes and smoke-tests the model → three
valid GGUF files (F16, Q5_K_M, Q4_K_M) in about 35 s. Both laptops share one MongoDB Atlas
database, so a job started on Huzaifah's website is run by Sibghatullah's worker.

When something goes wrong, the job stops cleanly with an error code, a plain message and a fix, and
leaves no half-made files behind.

## Highlights

- **Preflight** (WP-08): catalog, levels, profile, free disk, free RAM, licence, HF token, llama.cpp
  version and the 2-job limit — each with a tick or a cross, the reason, the fix and the code.
- **Jobs API** (WP-10): `POST /api/jobs` answers `202` at once (preflight runs again on the server);
  `GET /api/jobs/:id` gives status, stage, %, queue position and the latest 50 log lines.
- **Worker** (WP-11): takes the oldest queued job in one atomic step (never twice), heartbeat every
  10 s, cancel between stages, crashed jobs → `E-WORKER-01`.
- **Job Progress page** (WP-12): stage stepper, progress bar, elapsed time, live log, error card,
  "FAKE DATA" badge; polls every 2 s and stops when the job ends.
- **Hardening** (WP-13): timeouts stop the tool and everything it started; a 2 GB disk reserve
  (`E-DISK-01`); failed / cancelled / crashed jobs leave no files; downloads resume.
- **Every catalog model tried** (WP-09): 7 of 8 compress and pass the smoke test, up to
  Phi-3.5-mini (3.8 B); the gated Llama-3.2 needs a Hugging Face token.
- **Regression check** (`npm run regression`): the three demo models give **byte-for-byte the same
  file sizes** as the earlier measurements — see [regression-M2.md](../regression-M2.md).
- **112 automated tests**, CI on every PR.

## Known limits

- Cancel stops a job **between** stages; stopping a running tool at once and the Cancel / Retry
  buttons come in Phase 4 (WP-22 / WP-23).
- Speed, RAM, perplexity, the recommendation, the results page and downloads come in Phase 3 (M3).
- Run only **one** worker against the shared Atlas database (a fake worker would take real jobs).
- Preflight measures disk and RAM of the machine running the API — for real jobs, run the API on
  the model machine.
