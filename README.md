# PocketPrune — Edge LLM Compression & Deployment Toolkit

BSCS Final Year Project, Lahore Garrison University.
Team: Huzaifah Saleem · Sibghatullah — Supervisor: Ms. Hafsa Tahir · Co-supervisor: Ms. Unaisa Batool.

PocketPrune takes a small open-source language model from Hugging Face, compresses it to GGUF
(Q5_K_M / Q4_K_M) with llama.cpp, measures size, speed, RAM and perplexity, and recommends the best
file for your device.

Setup and run instructions arrive with WP-01. Project rules live in [CLAUDE.md](CLAUDE.md);
the SRS and roadmap are in [docs/](docs/).
